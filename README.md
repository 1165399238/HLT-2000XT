1.辐射防护监测系统HLT-2000XT
  实时数据采集：辐射监测系统通过专业计算机串口设备服务器虚拟的串口通讯方式,与各种辐射监测设备通讯,实时采集各监测设备的实时数据和报警数据，
进行显示和存储。
     数据处理: 辐射监测专用计算机能对采集和输入的监测数据进行分析和处理,并以报表形式列出。
  远程发送指令: 在工作台可以通过辐射监测专用计算机向就地处理单元发送报警阈值的查询和修改命令；能控制远程继电器的开和关(需要传输5伏电压)
  实时显示报警: 以图形或者表格实时显示各监测点的测量数据值、参数、报警状态;
数据储存和查询：辐射监测专用计算机自动将采集到的各种数据存入数据库中，并能查询任意现场监测设备的历史数据和历史曲线;
历史数据的查询可根据探测装置编号、日期、报警状态等多种方式对保存的历史数据进行查询并显示；
     数据采集: 根据现场各个监测设备的安装位置,将各测量数据通过RS485总线传输到基于网络的串口设备服务器,串口设备服务器将多个端口的RS485
设备联入基于TCP/ip的以太网，与工作台辐射防护监测系统专用计算机共同接入以太网交换机,建立以太网。
              虚拟串口模式可以将串口服务器的串口映射到计算机中,成为计算机的com端口，实现透明的网络协议至串行通讯协议的转换,获取辐射监
测设备的数据.
